# Opening an Issue

Thank you for taking the time to report a problem or suggest an improvement!  
To help us resolve issues faster, please follow the guidelines below.

---

## Bug Reports

When reporting a bug, include:

1. **Meaningful issue title**  
    Use a clear, concise title that summarizes the problem or request. Avoid vague titles like “doesn’t work” or “help.” Instead, describe the core issue such as “judgels-client shows Internal Server Error on homepage”.

2. **Description of the issue**  
   What happened? What did you expect?

3. **Steps to reproduce**   
   Provide commands, configuration, or actions needed to trigger the issue.

4. **Environment details**   

   * OS / Linux distro
   * Docker version
   * Kernel version (`uname -r`)
   * Judgels version used
   * Any relevant configuration files

5. **Attachments**   
   If possible, include stack traces or container logs inside code blocks and screenshots of the issue.

---

## Documentation Issues

If you found outdated, unclear, or incorrect documentation:

* Link to the affected file or section
* Provide a screenshot, if helpful
* Suggest a possible correction

---

We appreciate your help in improving this project!
